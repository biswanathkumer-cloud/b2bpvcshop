SECURE CUSTOMER + OWNER ADMIN SETUP
===================================

এই version-এ Customer এবং Owner/Admin—দুজনের login server-side Cloudflare Worker + D1 database-এ চলে।
Customer password PBKDF2 + random salt দিয়ে hash হয়। Owner password-ও server-side D1-তে hash হয়ে থাকে।
কোনো owner/customer password index.html-এ রাখা হয় না।

D1 SETUP
--------
1. Cloudflare Dashboard -> Workers & Pages -> আপনার Worker খুলুন।
2. D1 Databases -> Create database -> নাম: b2bpvcshop-db
3. Database ID copy করুন।
4. wrangler.jsonc-এ PASTE_YOUR_D1_DATABASE_ID_HERE-এর জায়গায় Database ID বসান।
5. D1 Console -> Query -> schema.sql-এর পুরো SQL একবার run করুন।

OWNER PASSWORD (প্রথমবার)
--------------------------
Cloudflare Worker-এর Environment Variable/Secret হিসেবে সেট করুন:
ADMIN_INITIAL_PASSWORD

Value হিসেবে নিজের একটি strong password দিন (কমপক্ষে 8 characters; বড়/ছোট অক্ষর, সংখ্যা ও symbol ব্যবহার করুন)।

প্রথমবার Owner Login করলে এই password দিয়ে owner account D1-তে তৈরি হবে। এরপর password D1-তে hash হয়ে থাকবে।
ADMIN_INITIAL_PASSWORD পরে বদলালেও existing owner password বদলাবে না।

Owner username: owner

OWNER LOGIN
-----------
Website -> Owner Administration Login -> username owner -> আপনার ADMIN_INITIAL_PASSWORD

Owner Panel-এর Change Password ব্যবহার করে পরে নতুন password সেট করতে পারবেন।
Password change-এর পরে পুরনো owner sessions invalidate হবে এবং নতুন password দিয়ে আবার login করতে হবে।

CUSTOMER LOGIN
--------------
Customer Create Account -> Mobile + Password -> Login.
Customer নিজের profile, cart, orders, feedback/complaint দেখতে পারবে। অন্য customer-এর data API authorization ছাড়া পাওয়া যাবে না।

DEPLOY
------
GitHub repository-তে index.html, worker.js, wrangler.jsonc, schema.sql রাখুন।
D1 binding name অবশ্যই DB হতে হবে। Worker deploy করুন।

গুরুত্বপূর্ণ:
- Static HTML alone দিয়ে secure multi-user authentication করা যায় না; Worker + D1 deploy বাধ্যতামূলক।
- এই package-এ Owner login-এর কোনো localStorage fallback নেই।
- Production deployment-এর আগে ADMIN_INITIAL_PASSWORD secret অবশ্যই Cloudflare secret হিসেবে সেট করুন; source code-এ লিখবেন না।
- Payment verification এবং automated payment gateway আলাদা বিষয়।
