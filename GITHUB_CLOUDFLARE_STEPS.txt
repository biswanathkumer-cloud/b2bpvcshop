GitHub + Cloudflare deployment

Repository root must contain:
- public/index.html
- worker.js
- wrangler.jsonc
- schema.sql
- README_BN.txt
- SETUP_SECURE_LOGIN.txt

Do NOT put worker.js, wrangler.jsonc, or schema.sql inside public/.
Before deploy, replace PASTE_YOUR_D1_DATABASE_ID_HERE in wrangler.jsonc with your D1 database ID.
Set ADMIN_INITIAL_PASSWORD as a Cloudflare Worker secret; do not put the password in GitHub.
